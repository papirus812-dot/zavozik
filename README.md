# «Завозик» — сайт молочной марки

Статический сайт на HTML, CSS и JavaScript, без сборки. 3D-сцены — на Three.js (подключается с jsDelivr).

- `index.html` — заставка, `home.html` — главная.
- Главы: «Кто мы?», «Производство», «Молоко», «Сыры», «Доставка»; каталог с корзиной и карточками товаров.
- Игра «Молочная ферма» открывается кнопкой «Программа лояльности».

Цены на сайте указаны для примера, оформление заказа и оплата не подключены.

## Как открыть у себя

Нужен [Node.js](https://nodejs.org/):

```
node tools/serve.js
```

Затем откройте http://localhost:5173/

## Чужие материалы

- Фермер в главе «Кто мы?» — рендер модели Microsoft Rocketbox, лицензия MIT: `assets/img/farmer-LICENSE.txt`.
- Шейдер заставки — Paper Shaders, лицензия MIT: `assets/vendor/paper-shaders/LICENSE`.
- Фотографии в главе «Производство» — Wikimedia Commons, авторы и лицензии подписаны под снимками на сайте.
